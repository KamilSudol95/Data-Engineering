# 🐼 Pandas: Mastering Fundamentals & Best Practices

This repository serves as a comprehensive log of my journey back to the roots of **pandas**. While I use pandas in my daily workflow, I am revisiting the library from the ground up to solidify my understanding, eliminate bad habits, and adopt the latest industry standards.

## 🎯 Project Objective
To move beyond "code that just works" toward code that is **memory-efficient, performant, and idiomatic**. This project specifically focuses on the transition to **Pandas 3.0+** and its internal optimizations (like Copy-on-Write).

## 🏗️ Curriculum & Roadmap
The project is structured into 12 distinct modules based on my Jupyter Notebook curriculum:

-   **02. Series At Glance** – Deep dive into `pd.Series` architecture, indexing, and underlying `dtypes`.
-   **03. Series Methods & Handling** – Mastering built-in methods and prioritizing vectorized operations over loops.
-   **04. Working With DataFrames** – Essential DataFrame operations, creation, and selection.
-   **05. DataFrames in Depth** – Advanced filtering, slicing, and selection using `.loc` and `.iloc`.
-   **06. Working With Multiple DataFrames** – Merging, joining, and concatenation best practices.
-   **07. Going MultiDimensional** – Understanding and utilizing Hierarchical Indexing (MultiIndex).
-   **08. GroupBy & Aggregates** – Efficient split-apply-combine operations.
-   **09. Reshaping With Pivots** – Restructuring data efficiently (pivots, stack/unstack).
-   **10. Handling Time & Date** – Timeseries analysis and datetime manipulations.
-   **11. Regex & Text Manipulation** – Clean data using vectorized string operations and regular expressions.
-   **12. Visualizing Data** – Creating quick insights with pandas' built-in plotting.
-   **13. Data Formats & I/O** – Mastering input/output operations (CSV, Excel, JSON, Parquet).

## 🛠️ Tech Stack & Dependencies
This project is running on **Python 3.12+**. The specific dependencies (including **Pandas 3.0.0**) are managed in the `requirements.txt` file.
